# Termos Justos

Ferramenta web para análise automática de cláusulas abusivas em contratos, com suporte a múltiplos idiomas (PT, EN, ES).

## 🚀 Funcionalidades
- Upload de contratos em **TXT, PDF, DOCX**
- Detecção automática de idioma
- Identificação e destaque de cláusulas abusivas
- Exportação de relatórios em **PDF** e **DOCX**
- Interface simples e intuitiva (Flask + HTML/CSS)

## 🛠️ Instalação
Clone o repositório e instale as dependências:

```bash
git clone https://github.com/seu-usuario/termos-justos.git
cd termos-justos
python -m venv .venv
source .venv/bin/activate   # Linux/Mac
.venv\Scripts\activate      # Windows
pip install -r requirements.txt
```

## ▶️ Uso

flask run
- Depois abra http://localhost:5000 no navegador.
